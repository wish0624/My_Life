# MyLife
**Your Life, Your Space.**

MyLife 是一个供本人及受邀朋友使用的个人生活管理 Web 网站。用户通过公网链接访问，无需获取源码或安装开发环境。

## 已确认决策
- 产品形态：响应式平面 Web 网站。
- 视觉：Modern Spatial UI + 3D Editorial Design；现代、偏写实、有质感。
- 主题：Mixed Theme，暖白与深色按页面场景组合。
- 动效：Rich Motion，包含悬浮、视差、滚动动画、转场和微交互。
- 3D：不做 3D 游戏世界、浮岛地图或自由漫游；优先 CSS 3D、Motion、GSAP。确有必要再引入 Three.js。
- 第一阶段：衣橱与虚拟穿搭。
- 核心能力：问题/答案验证登录、多用户数据隔离、衣物数字化、虚拟真人形象、AI 试穿、穿搭保存。

## 开发原则
先完成设计规范与关键页面原型，再开始业务开发；先做一个可用闭环，再扩展其他生活模块。未经确认，不得擅自改变已确认的产品和视觉方向。
