# 设计哲学

定位：**Modern Spatial UI + 3D Editorial Design**。现代、偏写实、有质感的平面 Web 产品，以层次、透视、材质、光影和动效建立个人数字空间体验。

## 已确认决策
- Mixed Theme：暖白与深色按页面场景组合，不是强制全站单一明暗。
- Rich Motion：悬浮、视差、滚动动画、转场和微交互。
- Flat Web：标准平面网页，不做 3D 游戏世界、自由漫游或浮岛地图。
- Modern & Realistic：避免卡通、手绘、Low-poly 风格。
- Functional First：业务页面首先保证清晰、高效、易操作。

## 设计原则
1. 层次感优先于装饰堆砌。
2. 图片与真实内容优先于无意义 3D 装饰。
3. 动效必须表达状态、方向或反馈。
4. 同类组件在不同模块保持一致。
5. 首页可更有表现力，业务页应更克制。
6. 主题可变化，但字体、间距、圆角、动效曲线和交互状态统一。
7. 移动端不是桌面端的简单缩小版。

## 避免
过量玻璃拟态、霓虹渐变、蓝紫科技风；所有卡片都悬浮倾斜；大面积持续动画；动画遮挡关键操作；过多分割线和同权重卡片；只做静态稿而不设计加载、空、错误、成功和禁用状态。
