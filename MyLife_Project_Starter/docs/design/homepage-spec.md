# 首页 UI 方案

## 首页目标
建立 MyLife 品牌印象，让用户快速理解平台并进入生活模块。首页不是数据密集型 Dashboard。

## 页面结构
1. 顶部导航：品牌标识、模块入口、个人菜单。
2. Hero：深色视觉主区域；主标题、简短品牌文案、主操作入口；具有空间层次的 3D 编辑式视觉素材。
3. Personal Space：生活模块卡片区，采用明暗交错的模块视觉卡片。
4. Recent Activity：最近使用或最近更新的内容，控制信息密度。
5. Footer：版本、隐私与基础信息。

## 文案方向
品牌：MyLife.
主标题：Your life, beautifully organized.
辅助文案：A personal space for everything that matters.
主操作：Explore your space / Enter Wardrobe（按实际功能状态显示）。

## 视觉要求
深色 Hero 与暖白内容区形成对比；素材采用现代、写实、建筑/产品摄影式质感；不采用卡通、手绘、Low-poly、游戏地图或浮岛场景；不堆砌无意义图标和悬浮卡片。

## 必须设计的状态
首次加载、已登录、无最近活动、模块未开放、移动端导航展开、网络错误。
