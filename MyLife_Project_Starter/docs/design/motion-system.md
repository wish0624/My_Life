# Motion System

## 动效等级
- Micro：按钮、图标、开关，150–220ms。
- Hover：卡片浮起、轻微倾斜，250–350ms。
- Transition：页面切换、面板展开，350–500ms。
- Scroll：滚动视差、内容进入，500–800ms。
- Hero：首屏视觉演出，800–1200ms。
这些是参考区间，不是每个动画必须达到的固定时长。

## 允许的效果
首页标题与视觉元素分层进入；背景轻微视差；模块卡片悬停上浮、轻微倾斜、阴影变化；面板展开；图片切换；页面共享元素过渡；AI 生成状态和结果呈现动画。

## 约束
- 鼠标倾斜通常不超过 3–5 度；悬浮位移通常 4–10px。
- 不允许大面积闪烁、快速缩放或无意义循环。
- 同一屏避免多个强动效同时争夺注意力。
- 动画不能延迟关键操作或影响点击准确性。
- 支持 `prefers-reduced-motion`。
- 移动端减少视差、粒子和高成本动画。

## 技术策略
主要使用 Motion；复杂滚动时间轴使用 GSAP。优先 CSS transform/opacity，避免频繁触发布局计算。暂不默认引入 Three.js。
