# 响应式规范

状态：P0 执行基线。本文件独占断点、容器和布局数值；字体、组件尺寸见 [Design System](design-system.md) 与[组件规范](component-spec.md)。所有宽度为 CSS px，按可用视口而不是设备型号判断。

## 1. 断点与布局 Token

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ml-bp-compact` | 480px | 手机卡片由 1 列变 2 列的唯一附加断点 |
| `--ml-bp-md` | 768px | 平板起点 |
| `--ml-bp-lg` | 1024px | 桌面起点、完整导航 |
| `--ml-bp-xl` | 1280px | 宽桌面、三栏工作台 |

移动为 320–767px，平板 768–1023px，桌面 >= 1024px。320px 是最小验收宽度，不能给 body 设置更大的 min-width。CSS 采用 mobile-first 的 min-width 查询，精确在断点处启用更大布局，不留 767/768 之间的小数空隙。

断点 Token 是规范/构建常量名；CSS 自定义属性不能直接放进原生 @media 条件。P1 将同一数值映射到 Tailwind 断点或统一媒体查询常量，不在各组件散写另一套值。

| 布局 Token | 移动 | 平板 | 桌面 |
| --- | --- | --- | --- |
| `--ml-layout-gutter` | 16px | 32px | 40px |
| `--ml-layout-grid-gap` | 16px | 24px | 24px |
| `--ml-layout-grid-columns` | 4 | 8 | 12 |
| `--ml-layout-section-gap` | 48px | 64px | 80px |
| `--ml-layout-nav-height` | 64px | 72px | 80px |
| `--ml-layout-page-top` | 24px | 32px | 48px |

| 固定布局 Token | 值 | 用途 |
| --- | --- | --- |
| `--ml-layout-content-max` | 1200px | 首页、衣橱、一般内容容器 |
| `--ml-layout-studio-max` | 1440px | 宽工作台容器 |
| `--ml-layout-form-max` | 640px | 单列表单内容 |
| `--ml-layout-control-panel` | 320px | 桌面工作台控制区 |
| `--ml-layout-selector-panel` | 280px | 宽桌面衣物选择区 |

容器宽度 = min(最大宽度, 100% - 2 × gutter)，居中。通栏背景独立于内容容器。栅格内部一律 minmax(0, 1fr)，子项 min-width: 0；内容超长要换行，不能把列撑出视口。表单最大宽度不代表居中所有业务工作台。

## 2. 页面与组件布局矩阵

| 区域 | 移动 | 平板 | 桌面 |
| --- | --- | --- | --- |
| 导航 | 品牌 + 账户/菜单按钮；模块入口在 Sheet | 同移动；不挤入完整桌面菜单 | 完整导航；固定顶部，使用页面规范指定的导航主题，不随滚动自动换色 |
| Hero | 文案在上、媒体在下；无强制视口高度 | 上下排；文案不挤在图片一角 | 两列 5:7；最小高度 640px；短视口允许内容撑高 |
| Personal Space 模块卡 | 1 列 | 最多 2 列 | 最多 3 列；仅有衣橱时使用一张特色卡，不补假功能 |
| Recent Activity | 1 列列表 | 2 列 | 最多 3 列 |
| 衣物/形象卡集合 | < compact 为 1 列；>= compact 为 2 列 | 3 列 | 4 列 |
| 字段表单 | 单列，按钮可占满容器 | 默认单列，短关联字段可并排 | 默认单列；并排只用于同一语义组 |
| Outfit Studio | 人物预览 → 已选摘要 → 选择/生成；选择器用全屏 Sheet | 预览在上、控制面板在下；衣物选择可用 Sheet | < xl 为预览 + control-panel 两列，选择器用 Sheet；>= xl 为 selector-panel + 预览弹性列 + control-panel |
| 筛选/工具栏 | 换行，筛选入口打开 Sheet | 行内换行 | 同行布置，内容不足时允许换行 |

- DOM 与当前视觉阅读顺序一致：宽桌面为选择器 → 预览 → 控制；紧凑视口将选择器移入由按钮触发的 Sheet，主内容为预览 → 选择摘要与操作。不能只用 CSS order 制造与键盘顺序相反的布局；切换时复用同一份选择状态。
- 桌面两栏/三栏工作台只使用 studio-max 容器；不要将固定侧栏塞入 content-max 后压缩人物预览。预览列最小可用宽 320px，放不下时使用下一档单列规则。
- 手机不采用横向自由拖拽画布。Tabs 过多可在自身容器内横向滚动并确保聚焦项可见；页面本身不能横向滚动。
- 表单操作组窄屏垂直排列，主操作在前且占满容器；桌面靠末端对齐。操作视觉顺序与 DOM 相同。
- 控件高度不随屏幕缩小，使用全局 control-height 与 target-min。触屏不是缩减命中区的理由。

## 3. 弹层、固定区域与键盘

- 确认/简短 Dialog 保持居中，宽度上限来自组件规范；最大高度 min(85dvh, 100dvh - 2 × gutter)，内容区内部滚动，标题与关闭按钮可见。
- 移动端长表单编辑、衣物选择和大图预览用全屏 Sheet，宽 100%、高 100dvh；不要把桌面三栏压进小弹窗。平板/桌面使用侧向 Sheet，移动从底部进入。
- Sheet/弹窗外壳预留 env(safe-area-inset-top/bottom)；正文区域 min-height: 0，可滚动；操作区不能盖住最后一个字段。
- 固定底部操作栏若页面需要，基础内边距 space-3 + 底部安全区；内容区额外预留栏的实际高度。不得仅以固定 64px 猜测放大文字后的高度。
- 软键盘出现后，当前输入、错误提示和提交动作可滚动到可见位置；不要全屏锁死页面高度。对不支持 dvh 的浏览器提供 vh 回退并真机检查。
- nav-height 为导航最小高度，放大文字后允许增长；锚点/聚焦滚动使用导航实际高度 + space-4 的 scroll-margin-top，默认实际高度等于 nav-height，避免被固定导航遮挡。
- 设备旋转/调整窗口不会重置表单、任务或选中值。跨断点切换同一弹层时保持一次打开状态、焦点和语义，不同时挂载两套可聚焦内容。

## 4. 图片、文字与输入能力

- 首页媒体桌面/平板使用 16:10，移动使用 4:3；业务媒体固定比例沿用组件规范。手机另交裁切稿，不能只缩小桌面素材。
- 静态素材使用适当的 srcset/sizes；按显示尺寸及 DPR 选择，不强制给手机下载桌面原图。Hero 首屏资源优先，以下内容按需加载。
- 字号按 Design System 的角色表切换，正文不因移动端变为更小号；允许 200% 文字放大，不锁 viewport 缩放。
- 长中文、超长英文名、URL 都有可读换行；URL 可 overflow-wrap:anywhere。姓名/名称不能为了居中强行缩到无法阅读。
- 视差与倾斜由“宽度 + pointer/hover + reduced motion”共同决定；大屏触控平板不自动获得鼠标效果。详见 Motion 的降级规则。
- 布局仅影响呈现，不删掉移动端的上传、编辑、预览、重试或保存任务。

## 5. 验收宽度

必测 320、390、768、1024、1440px；断点边界额外测 479/480、767/768、1023/1024、1279/1280px。还需移动横屏、短视口 1024×600、200% 文字缩放，以及 1280px 视口在 400% 缩放时的 320 CSS px 重排。检查内容、焦点、弹层、固定导航和软键盘，截图与结果按[设计验收](design-acceptance.md)记录。
