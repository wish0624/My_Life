# Definition of Done

一个页面或功能只有满足以下条件才算完成：

## 体验
- [ ] 主要用户任务可独立完成。
- [ ] 桌面和移动端布局经过检查。
- [ ] Loading、Empty、Error、Success、Disabled 状态齐全。
- [ ] 键盘焦点和基本可访问性通过检查。
- [ ] 动效符合 Motion System，支持减少动态效果。

## 设计
- [ ] 使用 Design Token，不随意硬编码颜色和间距。
- [ ] 同类组件视觉与交互一致。
- [ ] 图片比例、裁剪、占位和失败状态明确。
- [ ] 没有为装饰而牺牲信息层级。

## 工程
- [ ] TypeScript 类型明确，无不必要的 any。
- [ ] API 错误有处理，用户可理解并恢复。
- [ ] 关键路径有测试。
- [ ] 权限校验在服务端完成。
- [ ] 不泄露密钥、验证答案或私人图片。
- [ ] 日志、性能和成本有基本监控。
