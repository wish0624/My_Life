# 开发路线与阶段验收

## P0：产品与设计准备（当前）
交付：产品概述、功能需求、用户旅程、Design System、首页方案、架构草案。
验收：视觉方向无歧义；首页和衣橱关键页面有线框/高保真稿；技术与安全边界明确。

## P1：前端基础与首页
- 初始化 React + TypeScript 项目。
- 实现主题 Token、字体、基础组件和动效封装。
- 完成响应式首页、导航和模块入口。
验收：桌面与手机可用；组件状态完整；动画流畅且支持 reduced motion。

## P2：后端与多用户
- FastAPI、PostgreSQL、对象存储。
- 管理员创建用户与设置问题/答案。
- 登录会话、限流、数据归属校验。
验收：至少两个测试用户；用户 A 无法读取、修改、删除用户 B 的任何数据或文件。

## P3：衣物数字化
- 图片上传、网址解析兜底、原图/处理图存储。
- 背景移除、属性识别、人工编辑。
验收：上传、处理、失败重试、编辑和删除闭环完成。

## P4：虚拟形象与试穿
- 虚拟形象创建与管理。
- AI Provider Adapter。
- Outfit Studio、生成任务状态、结果保存。
验收：从选择形象和衣物到生成、预览、保存形成完整闭环；隐私与成本控制通过检查。

## P5：部署与扩展
- 域名、HTTPS、Docker 部署。
- 备份、日志、监控、错误处理。
- 安全与移动端验收。
验收：朋友可通过公网访问；无需源码；账号隔离测试通过。

## 当前不应提前做
- 不要一次性实现所有未来生活模块。
- 不要先做复杂 3D 场景。
- 不要在 API 方案未验证前训练模型。
- 不要在多用户权限未通过测试前开放真实用户数据。
