# 安全与隐私检查清单

## 登录
- [ ] 答案只在服务端验证。
- [ ] 使用安全密码哈希，不保存明文。
- [ ] 登录尝试限流。
- [ ] HTTPS 与 Secure、HttpOnly、SameSite Cookie。
- [ ] 会话过期、退出登录和凭据重置机制。
- [ ] 错误提示不泄露可用于枚举账号的敏感信息。

## 数据隔离
- [ ] 所有业务查询从会话读取 user_id。
- [ ] 读取、修改、删除均校验归属。
- [ ] 关联资源校验属于同一用户。
- [ ] 文件下载采用权限校验或短时签名 URL。
- [ ] 管理员权限与普通用户权限分离。
- [ ] 测试用户 A 无法访问用户 B 的记录和文件。

## 图片与 AI
- [ ] 限制文件类型、大小和图片尺寸。
- [ ] 对上传文件进行实际格式检查，不只信任扩展名。
- [ ] 防止恶意文件和不安全 URL 抓取。
- [ ] 明确真人照片是否会传输给第三方 AI 服务。
- [ ] 提供原图、形象图和生成结果的删除能力。
- [ ] 日志不记录验证答案、图片内容或不必要的个人信息。
- [ ] 配置 AI 调用预算、超时、重试和速率限制。
