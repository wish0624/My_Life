# 核心用户旅程

## 登录
打开 MyLife → 选择/识别身份 → 回答管理员配置的问题 → 服务端验证 → 建立会话 → 进入个人首页。
异常：答案错误提示、尝试限流、账号停用提示、会话过期后重新验证。

## 添加衣物
进入 Wardrobe → 添加衣物 → 上传图片或粘贴网址 → 系统提取/处理图片 → 用户确认图片并编辑属性 → 保存 → 返回衣物列表。
要求：明确显示上传、识别、去背景、等待确认等状态；失败时保留原始素材并允许重试。

## 创建虚拟真人
进入 Avatar Studio → 阅读照片用途和隐私说明 → 上传参考照片 → 填写可选参数 → 提交生成 → 查看候选结果 → 选择并保存 → 管理形象。

## 创建穿搭
进入 Outfit Studio → 选择形象 → 选择衣物 → 检查组合 → 生成 → 查看进度 → 预览结果 → 保存方案。
要求：选择过程中不应每选一件衣服就调用 AI；用户确认后再提交生成。
