# 产品概述

## 定位
MyLife 是一个个人生活管理平台，不是传统后台，也不是纯展示型作品集，而是一个具有鲜明视觉体验、可长期使用的个人数字空间。

## 用户
- 管理员：管理用户身份、验证问题/答案和基础配置。
- 普通用户：使用独立身份登录，只能访问自己的数据。
- 朋友通过公网网址访问，无需源码或本地开发环境。

## 产品原则
1. 视觉吸引力与日常效率并重。
2. 立体感来自层次、透视、材质、光影和动效，不是所有元素都做成悬浮卡片。
3. 首页负责品牌感与模块发现；业务页负责高效完成任务。
4. AI 是能力，不是强制入口。
5. 生成结果应可预览、确认、保存、重试或删除。
6. 用户数据私密，关键操作有明确反馈。

## 信息架构
平台基础：登录、用户身份、首页、导航、设置、权限、文件资源。

第一阶段 Wardrobe：
- 我的衣物、添加衣物、衣物详情与编辑
- 虚拟真人形象
- Outfit Studio（虚拟穿搭）
- 穿搭收藏与历史

未来候选模块（不属于第一阶段交付承诺）：知识与学习、生活记录、日程与计划、个人财务等。

## 明确不做
- 不做可自由漫游的 3D 游戏世界或浮岛地图。
- 第一版不开发真正的实时 3D 人体、骨骼绑定和布料模拟。
- 未验证体验前不训练自有试穿模型。
- 不让动效牺牲可访问性、移动端体验或性能。
