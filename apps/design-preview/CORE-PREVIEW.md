# 光启控制台

Windows 双击 `start-core-preview.cmd` 或 `start-preview.cmd`，即可打开[本机预览](http://127.0.0.1:4173/design-preview/core)。预览服务的根路径和 `/design-preview` 也默认进入点火页。A/B 的旧样张保留在浏览设置中。

## 三屏操作

| 屏幕 | 如何操作 |
| --- | --- |
| 光启核心 | 待机时外环缓转。将指针移到反应堆或“启动”上，光芯提亮，外侧导线展开。点击或按 Enter、空格点火后进入总览。启用减少动态效果时直接切换。 |
| 模块总览 | 从数字衣橱、虚拟形象、穿搭工作台中选择一个模块。三块入口分别使用金属衣架、全息人像和线框夹克标识。 |
| 模块工作区 | 在衣橱筛选、查看详情及点亮星标，在形象页切换全身和局部，在穿搭页添加或移除夹克。点返回箭头可选择其他模块。 |

页面一次挂载一个工作区。点击切屏会更新地址，浏览器前进、后退及刷新可以还原当前屏。底栏标示所在层级。滚轮和触摸滑动不会带出下一屏，弹窗在较小视口中可单独查看。收藏与搭配仅保留在当前页面会话内。

## 视觉与功能范围

模块卡片在悬停或键盘聚焦时分别显示取景框、人物扫描线和合拢的双环。触屏点一次即可进入模块。底栏的三个图标标记所处层级，浏览设置可随时关闭动态效果。[素材记录](ASSETS.md)

该预览提供本机交互。账号、上传、AI 人像生成和 AI 试穿仍待开发。

## 验证

先启动本机预览服务，再执行 `npm run build`、`npm run test:core` 和 `npm test`。Core 浏览器测试检查实际挂载页数、页面和内容区尺寸、滚轮、点火、焦点、浏览历史、模块操作、触屏模拟及图片异常。机器报告与桌面、平板、手机截图位于 `.qa/core/`。A/B 的报告位于 `.qa/browser-report.json`。
